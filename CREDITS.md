## Models and textures

- **Models:** none imported. Every object is built in code from cubes, quads,
  cylinders, spheres, cones and tori (`src/gfx/Primitives.cpp`).
- **Textures:** all PNG files in `assets/textures/` are generated by our script
  `tools/generate_textures.py` (value noise and simple drawing with NumPy and Pillow).
  No external images.
